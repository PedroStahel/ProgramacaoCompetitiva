# 🧠 Programação Competitiva

Repositório pessoal de **resolução de problemas de programação**, utilizado para praticar raciocínio lógico, algoritmos, interpretação de enunciados e implementação de soluções.

Os exercícios são provenientes do **LeetCode**, conforme a proposta original deste repositório. As soluções estão escritas principalmente em **C**, com alguns exercícios em **Python**.

## 🎯 Objetivos

- Desenvolver raciocínio lógico e capacidade de abstração.
- Praticar a transformação de enunciados em algoritmos.
- Explorar diferentes abordagens para problemas de programação.
- Aprimorar a implementação e a análise de soluções em C e Python.
- Manter um histórico de estudos e evolução na resolução de desafios.

## 📚 Exercícios disponíveis

Alguns exemplos de soluções presentes no repositório:

| Arquivo | Tema |
|---|---|
| [`palindromo.c`](palindromo.c) | Verificação de palíndromos |
| [`romanoInt.c`](romanoInt.c) | Conversão de números romanos |

## 🛠️ Tecnologias

- **C:** implementação de algoritmos e manipulação de dados.
- **Python:** soluções concisas e exploração de recursos da linguagem.
- **Git e GitHub:** versionamento e acompanhamento dos estudos.

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/PedroStahel/ProgramacaoCompetitiva.git
cd ProgramacaoCompetitiva
```

Para um exercício em C, compile o arquivo desejado com GCC e execute o programa gerado:

```bash
gcc palindromo.c -o palindromo
./palindromo
```

Para um exercício em Python:

```bash
python3 stringReversa.py
```

**Observação:** alguns arquivos podem conter apenas funções de solução no formato esperado pela plataforma, sem um `main` ou entrada interativa. Nesses casos, devem ser testados com um programa auxiliar ou na própria plataforma.

## 📈 Evolução contínua

Este repositório é atualizado conforme avanço nos estudos de **algoritmos, estruturas de dados e resolução de problemas**. O foco é aprender com cada desafio, comparar estratégias e desenvolver soluções cada vez mais claras e eficientes.
